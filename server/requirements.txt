# Pipecat is installed EDITABLE from the git submodule at external/pipecat
# (pinned to the v1.5.0 tag), NOT from PyPI — this keeps the pipecat source in-repo
# so it can be tracked/patched. Flows is bundled in pipecat 1.5.0 (pipecat.flows),
# so there is no separate pipecat-ai-flows install.
#
# Install pipecat after these base deps. From the server/ directory:
#   # Native Windows / FreeSWITCH (default WebSocket transport):
#   pip install -e "../external/pipecat[websocket,anthropic,google,openai,deepgram,cartesia,elevenlabs,rime,silero]"
#   # Add the `daily` extra ONLY on Linux/WSL (daily-python has no Windows wheels):
#   pip install -e "../external/pipecat[daily,websocket,anthropic,google,openai,deepgram,cartesia,elevenlabs,rime,silero]"
#
# The `websocket` extra provides the FastAPI WebSocket transport used for FreeSWITCH.

# Base deps used directly by the server code (fastapi/uvicorn/loguru/aiohttp are
# also pulled transitively by pipecat; left unpinned to stay compatible with it).

pytz
fastapi
